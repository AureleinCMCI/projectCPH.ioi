# 📧 Guide d'Envoi du Flyer Animé

## 🎯 Méthode Recommandée : Hébergement Web

### Option A : GitHub Pages (Gratuit)

1. **Créer un compte GitHub** (si pas déjà fait)
   - Aller sur github.com
   - S'inscrire gratuitement

2. **Créer un nouveau repository**
   - Cliquer sur "New repository"
   - Nom : `conference-flyer`
   - Cocher "Public"
   - Cliquer "Create repository"

3. **Uploader le fichier**
   - Cliquer "uploading an existing file"
   - Glisser `index.html` dans la zone
   - Renommer en `index.html` si nécessaire
   - Commit : "Ajout flyer conférence"

4. **Activer GitHub Pages**
   - Aller dans Settings > Pages
   - Source : Deploy from a branch
   - Branch : main
   - Cliquer "Save"

5. **Votre lien sera** : `https://votre-username.github.io/conference-flyer/`

### Option B : Netlify (Plus Simple)

1. **Aller sur netlify.com**
2. **Glisser-déposer** votre fichier `index.html`
3. **Obtenir votre lien** automatiquement : `https://random-name.netlify.app`
4. **Personnaliser l'URL** (optionnel)

### Option C : Vercel (Professionnel)

1. **Aller sur vercel.com**
2. **Importer** votre fichier
3. **Déployer** en un clic
4. **URL personnalisée** disponible

## 🔧 Conseils Techniques

### Pour l'Envoi par Email
- **Testez d'abord** sur votre propre email
- **Vérifiez** que les liens fonctionnent
- **Utilisez** un objet clair et attractif
- **Ajoutez** votre signature professionnelle

### Pour l'Envoi par WhatsApp
- **Envoyez** d'abord à un contact test
- **Vérifiez** l'affichage sur mobile
- **Incluez** un message personnel

### Pour l'Envoi par Réseaux Sociaux
- **Publiez** à des heures de forte activité
- **Utilisez** des hashtags pertinents
- **Encouragez** le partage

## 📊 Suivi et Statistiques
